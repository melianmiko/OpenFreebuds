# HUAWEI FreeClip 2

Protocol: Huawei SPP, port 1

Device model: BTFT0027

Driver: `OfbDriverHuaweiFreeClip2`

## Features

- Fetch device information and battery level: ✅
- Set double-tap action: ✅
- Set triple-tap action: ✅
- Set long-tap action: ✅
  - w/ extra options (volume control)
- Set swipe gesture: ✅
- Equalizer: ✅
  - 4 built-in presets (default, hardbass, treble, voice)
- Sound quality preference (connectivity/quality): ✅
- Dual-device connection: ✅
- Low-latency mode: ✅
- Auto pause: ✅
- In-ear detection: ✅
- Voice language: ✅

## Not planned features

- Firmware update
- Head motion controls (nod/shake to answer) — needs SPP research
- Adaptive volume in noisy environments — needs SPP research
- Drop reminder — needs SPP research
