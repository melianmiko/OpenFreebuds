# HUAWEI FreeClip

Protocol: Huawei SPP, port 1

Uses the same driver as [HUAWEI FreeBuds Pro 3](./HUAWEI_FreeBuds_Pro_3.md).

## Features

- Fetch device information and battery level: ✅
- Set double-tap action: ✅
- Set swipe gesture: ✅
- Equalizer: ✅
  - 4 built-in presets
- Dual-device connection: ✅
- Low-latency mode: ✅
- Sound quality preference: ✅
- Auto pause: ✅
- In-ear detection: ✅
- Voice language: ✅

## Not planned features

- Firmware update
